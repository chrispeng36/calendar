# 「桌面日历」macOS 原生版 · 技术方案

> 对标产品：DesktopCal（桌面日历，desktopcal.com）——贴在电脑桌面上的日历，日期格即记事本。
> 目标平台：macOS 原生 App（Swift / SwiftUI）。本方案覆盖 MVP 全部功能域：桌面日历网格 + 点日期记便签、透明/酷炫视觉、闹钟提醒、农历节气节日、**导入/导出（云同步已砍）**、**桌面猫咪宠物 + 语音播报（支持多性格）**、**AI 大模型生成提醒文案**。

---

## 1. 产品定位与核心体验

DesktopCal 的本质不是"一个日历 App"，而是**把日历变成桌面本身的一层**：

- 常驻桌面、抬眼即见，不打断当前工作；
- **透明磨砂背景，与壁纸融为一体，视觉酷炫**；
- 双击某个日期格 → 就地记录待办/便签，操作路径极短；
- 有事项的日期自动着色，一眼看出当天安排；
- 附带农历/节气/节日信息，贴合中文用户习惯；
- 到点系统通知 + **桌面宠物语音播报**提醒；
- **AI 大模型按「事件 + 剩余时间 + 宠物性格」智能生成提醒文案**，再由 TTS 播报，让每次催办都自然、随性格变化；
- 一只**猫咪桌面宠物**常驻陪伴（形象来自用户提供的照片），会在事项临近截止时主动催你，**性格可由用户选择、由大模型驱动文案**。

**本方案的产品定义**：一款 macOS 原生应用，提供多种互补的呈现形态（详见 §3.4）：

1. **桌面层日历**（透明玻璃/酷炫主题，还原 DesktopCal 核心卖点，技术风险最高，见 §4.1）；
2. **主窗口全功能日历**（月/周/日视图 + 事项列表编辑）；
3. **桌面猫咪宠物**（独立透明窗口，形象来自 `pics/` 照片、多性格，与日历联动，见 §4.7）；
4. **可选桌面小组件**（macOS 14+ WidgetKit，补充入口）。

MVP 功能清单（已确认全部纳入）：

| 编号 | 功能域 | MVP 内容 |
|---|---|---|
| F1 | 桌面日历网格 + 记便签 | 月视图常驻；**透明磨砂/酷炫主题**；双击日期格快速记事；颜色/分类标注；日历/列表双视图 |
| F2 | 闹钟/提醒 | 事项设时间，系统本地通知 + **语音播报**；**默认提前 1 小时 + 半小时**双提醒；**提醒频率用户自选**（次数/间隔/可倒计时） |
| F3 | 农历 + 节气 + 节日 | 日期格副信息显示农历/节气/传统节日，可开关 |
| F4 | 导入/导出 | ICS 导入导出、CSV 导出（备份/跨软件交换）；**云同步已砍掉**，数据仅存本机 |
| F5 | 桌面宠物 + 语音 | **猫咪宠物**（形象来自 `pics/` 照片、**多性格可选**）；事项临近截止时**提前 1 小时/半小时主动语音播报**；宠物状态动画与语音联动 |
| F6 | **AI 大模型生成文案** | 用户配置**模型名称 + AK/SK 等连接信息**；大模型按事件/剩余时间/性格生成提醒文案 → TTS 播报；**不可用时自动降级本地模板**，提醒永不失效 |

依赖方向自上而下；业务层不感知 UI。`CopyGenerator`（AI 文案）只依赖 Domain 层接口，且**在任何异常（无 key/离线/超时/限流）下回退到本地模板文案**，因此对提醒链路是非阻塞的增强而非依赖项。交付/备份层只做本地导入导出，**无云端依赖**。

## 3. 关键技术选型

| 关注点 | 选型 | 理由 / 备注 |
|---|---|---|
| 语言 / UI | Swift + SwiftUI | 原生体验、与系统日历/通知无缝 |
| 最低系统 | **macOS 14 (Sonoma) 起**（目标），兼容 13 | 决定能否用 SwiftData、桌面 WidgetKit（需 14）；如用 GRDB 可降到 13/12 |
| 桌面贴底窗口 | `NSWindow` 透明无边框 + CoreGraphics 窗口层级 + `collectionBehavior`（见 §4.1） | **公开 API 之外有 hack，M0 必须 spike** |
| **透明/磨砂玻璃** | `NSVisualEffectView`（`blendingMode = .behindWindow`）+ SwiftUI `.ultraThinMaterial` / `.visualEffect`(macOS 14+) | 让日历窗口"透出壁纸并实时模糊"，是透明+桌面融合的关键 |
| **酷炫主题** | `ThemeEngine`：多套主题（玻璃/霓虹/流动渐变/极简）+ 自定义色板 | 动画用 `Canvas`/`TimelineView` 低帧率渲染，控制常驻功耗 |
| 本地存储 | **SQLite(GRDB) 为首选**；SwiftData 为备选 | 常驻+轻量+便于做变更日志；GRDB 迁移可控、不绑系统版本 |
| 农历/节气 | 第三方纯 Swift 库 `6tail/lunar-swift` | 功能全（农历/节气/节日/生肖/宜忌），需核对许可并做回归（见 §4.5） |
| 提醒 | `UNUserNotificationCenter` 本地通知 + 多提醒点 | `UNCalendarNotificationTrigger` 准点触发，自带时区 |
| **语音播报** | `AVSpeechSynthesizer`（`AVFoundation`）本地 TTS | 中文系统音色可选、语速可调，离线可用，无需麦克风权限 |
| **AI 文案** | **`LLMClient` provider 适配器**：OpenAI-compatible（含 DeepSeek/Qwen/GLM/Kimi/本地 Ollama 等）+ Anthropic | 用户可填 `baseURL`+`modelName`+apiKey 或 AK/SK；**密钥入 Keychain**；失败回退本地模板 |
| **桌面宠物** | **`pics/` 猫咪照片** + 独立透明窗口 + 轻微位移动画；`PetPersonality` 性格数据驱动 | v1 相框式呈现（原图+圆角/描边），预留系统抠图透明角色；性格可切换 |
| ~~云同步~~ | 已砍掉（需开发者签名+entitlements+iCloud 容器） | 数据仅存本机，用 ICS/CSV 备份转移 |
| 数据交换 | ICS 导入/导出 + CSV 导出 | 与桌面端/Google/Outlook 互通 |
| 分发 | Developer ID + 公证；可选 App Store / Sparkle 自动更新 | 桌面层窗口可能触发 Gatekeeper/沙盒限制，需早期验证 |
| 资源与启动 | 单常驻进程 + 菜单栏；无 Dock 图标可选 | 常驻软件必须低内存/低耗电 |

## 4. 模块设计

### 4.1 核心难点：桌面层日历窗口（F1 的地基）—— 需 M0 Spike

**目标状态**：一个透明日历窗口出现在**桌面壁纸之上、桌面图标/所有普通窗口之下**，且只有日期格可点击，桌面空白区域不抢鼠标事件。

**候选实现路线**（按还原度排序）：

| 路线 | 做法 | 优点 | 缺点/风险 |
|---|---|---|---|
| A. 桌面层 NSWindow | 无边框透明窗口；`level` 设在壁纸层与图标层之间；`collectionBehavior = [.canJoinAllSpaces, .stationary, .ignoresCycle]`；`canBecomeKeyWindow = false` | 还原度最高，接近 DesktopCal | 层级是**未文档化/非稳定 API**；新版 macOS（Ventura+ / Stage Manager / 多 Space）行为可能变化；可能吞掉"点桌面空白处"手势；需大量真机验证 |
| B. 低层级悬浮窗 | `level` 低于所有普通窗口（`kCGNormalWindowLevel - 若干`） | 层级用公开常量，稳定 | 仍浮在图标之上，非真正"桌面融合" |
| C. WidgetKit 桌面小组件（macOS 14+） | 系统原生把小组件放到桌面 | 系统背书、稳定、省电 | **交互极受限**：不支持"双击自由输入文本"，只能 App Intent/按钮，无法承载完整记事；只能只读展示 + 跳转主 App |
| D. 三态组合（**推荐**） | 默认 A 或 B 作为"桌面模式"；菜单栏/设置切换"普通窗口模式"；widget 补充 | 稳健，用户可按系统环境选择 | 工程量大一些 |

**M0 Spike 必须回答的问题**（1 周内验证）：
1. 在目标最低系统上，路线 A 的窗口能否稳定处于图标之下？切换 Space、开 Stage Manager、重启后是否保持？
2. 日期格点击命中 vs 桌面穿透（`ignoresMouseEvents` 动态切换 + `hitTest`）是否可行？
3. 双屏 / 换壁纸 / 屏幕解锁后层级是否丢失？
4. 是否影响用户点桌面图标的系统行为；是否需 Accessibility 权限。

**穿透与命中策略**：窗口默认忽略非日期区域的鼠标事件（空白格/边距设 `ignoresMouseEvents = true`，日期格动态关闭穿透）——既保留"点在空白桌面 = 系统默认行为"，又保证"点在日期上 = 进入记事"。

> 若 Spike 失败（路线 A 在最新系统不可行），降级顺序：A → B（浮在图标上但永居最底）→ C+D（只读 widget + 主窗口编辑）。产品上"桌面融合"退化为"极简常驻日历条/浮窗"，功能面不受损，只损失视觉融合度。

### 4.2 视觉与主题：透明 + 酷炫（F1）

**窗口透明基底**：
- `NSWindow.isOpaque = false`、`backgroundColor = .clear`、`hasShadow` 按主题开关；窗口内容做圆角。
- 磨砂玻璃：`NSVisualEffectView` 铺底，`material` 按主题（`.hudWindow` / `.popover` / `.underWindowBackground`），`blendingMode = .behindWindow` → **透出并实时模糊桌面壁纸**，是"透明融入壁纸"的落点。
- SwiftUI 侧叠加 `.background(.ultraThinMaterial)` 或 `.visualEffect { }` (macOS 14+)，用于前景控件（日期格、浮层）。

**主题系统（`ThemeEngine`）**，v1 内置 4 套 + 自定义：

| 主题 | 视觉要点 | 制作 |
|---|---|---|
| 玻璃 Glass | 透明磨砂 + 细描边 + 微阴影，透壁纸 | 默认，性能最友好 |
| 霓虹 Neon | 暗色基座 + 高饱和渐变描边 + 辉光（bloom），今天日期/hover 发光 | `Canvas` 绘制 + 低帧率光晕 |
| 渐变 Aurora | 多色流动渐变背景（慢速流动） | `TimelineView`/`Canvas` 动画帧率 ≤ 10fps |
| 极简 Minimal | 近纯透明，只留文字与日期格淡色 | 轻量 |

- **自定义**：用户选色板 / 透明度 / 动画强度 / 背景图（可"跟随系统壁纸取色"：`NSWorkspace` 取当前壁纸主色作为主题基调）。
- **省电**：无交互时动画停帧（或降至 ~2–5fps）；提供"性能模式"（全静态玻璃，关闭一切动画）。桌面层窗口长期可见，耗电与 CPU 必须受控，见 §7。

### 4.3 月历网格与日期格（F1）

- **渲染**：SwiftUI 月视图（`LazyVGrid` 7 列），周起始日可配（周日/周一）；支持月/周/日三档主视图切换。
- **日期格副文本**（自上而下）：公历日号 → 农历日/节气/节日徽标 → 事件指示点/条。
- **今日高亮 + 有事件日期着色**：颜色来自事项分类色，叠加主题光效。
- **交互**：
  - 单击日期格 → 选中并预览当天事项（小气泡）；
  - **双击 → `QuickCompose` 快速记录浮层**（无边框小窗，就近弹出，聚焦即输，`Esc` 关闭）——DesktopCal "比打开 APP 快 10 倍"的交互核心，必须不离开桌面窗口语境；
  - 右键/长按 → 上下文菜单（新建、复制、删除、去主窗口）。
- 可缩放字体/格子密度以适配不同分辨率屏幕。

### 4.4 记事/待办模块（F1）

**事件模型字段（v1）**：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | UUID | 主键（同步全局唯一） |
| `title` | String | 事项标题 |
| `body` | String? | 详情 |
| `startDate` / `endDate` | Date | 支持跨日/整日 |
| `startTime` | Date? | 定时提醒的基准时间 |
| `isAllDay` | Bool | 整日事项 |
| `categoryColor` | String | 分类颜色（红/橙/蓝/绿…） |
| `reminders` | `[Reminder]` | **多提醒点**（见 §4.6），替代单一 `remindAt` |
| `repeatRule` | 枚举 + 自定义间隔 | 不重复/每天/每周/每月/每年/工作日/自定义 |
| `isDone` | Bool | 完成态（划线/置灰） |
| `createdAt` / `updatedAt` / `deletedAt` | Date | 同步与软删除 |
| `source` | String | 手动 / ICS 导入，防回写覆盖 |

**能力**：日历视图（按天聚色块）+ 列表视图（未完成置顶、按日期分组、可勾选完成）；快速记录默认进入"今天"或所点日期。

### 4.5 农历 / 节气 / 节日（F3）

- 选用 `6tail/lunar-swift`：由公历 → 农历（含闰月）、节气、传统节日、生肖、宜忌。
- **显示优先级**（一格空间有限，只显示最重要的一条副文本）：`节日（如春节）> 节气（如清明）> 农历日（如三月初五）`；宜忌作为展开详情。
- **开关**：农历、节气、节日各自可开关。
- **注意**：苹果 `NSCalendarIdentifierChinese` 在部分年份区间（如 2057/9/28）数据有误，故不依赖系统实现；对 lunar-swift 覆盖区间做 1900–2100 抽样回归测试。

### 4.6 提醒调度：多提醒点 + 语音通道（F2）

**提醒点结构**：单 `remindAt` 升级为 `reminders: [Reminder]`，每个 `Reminder` 含：

| 字段 | 说明 |
|---|---|
| `offsetMinutes` | 相对 `startTime` 的偏移（负=提前，如 -60、-30；正=延后） |
| `scope` | `notification`（系统横幅）/ `voice`（语音播报）/ `both` |
| `label` | 可选备注 |

**默认提醒方案（用户点名的组合）**：`截止前 1 小时` + `截止前 30 分钟`，各一次，`scope = voice + notification`。

**频率自选**（全局默认 + 事件级覆盖）：

| 预设 | 行为 |
|---|---|
| 截止前 1 小时 + 半小时 | 两次（默认） |
| 仅截止前 1 小时 / 仅 30 分钟 | 一次 |
| 截止前 1 小时 + 半小时 + 10 分钟 + 准点 | 多点提醒 |
| 倒计时 | 截止前 N 分钟起，每 M 分钟语音播报一次；N、M 可自定义；可关闭防扰 |
| 自定义序列 | 用户自由增删多个时间点 |

**调度与补偿**：
- 权限：启动引导请求通知权限；被拒时在"今日概览"引导去系统设置开启。
- 触发：`UNCalendarNotificationTrigger` 本地通知 + `CopyGenerator`→`VoiceService`；重复事项按实例滚动生成 pending 通知。
- **补偿检查**：App 启动/进入前台时扫描错过的提醒点，若有（如电脑睡眠）→ 补一条提醒 + 宠物播报。
- 事件完成/删除 → 撤销对应全部 pending 提醒；事件完成后停止后续倒计时播报。
- **串行播报**：同一时刻多条语音进队列，逐条播放，避免混叠。

### 4.7 桌面猫咪宠物（F5）

**形态**：独立**透明窗口**承载宠物，层级与桌面层一致或略高；位置可拖动、吸附桌面角落，避免遮挡日历窗口；可整体隐藏（设置开关）。

**素材来源（用户指定）**：`pics/` 目录，含 6 张**同一只三花猫**的真实照片（`img.png`、`img_1.png`~`img_5.png`），姿态各异（床上探头、侧卧回望、沙发蜷缩、趴着回望、躺平、蹲在篮筐）。照片本身带背景，采用两种呈现：

| 呈现方式 | 说明 | 阶段 |
|---|---|---|
| **相框式（v1 默认）** | 直接使用照片原图，加圆角/描边/微阴影，作为「桌面宠物卡」 | M2 |
| **透明角色式（进阶）** | 用系统 Vision / CoreImage 自动抠像去掉背景，得到透明底角色，更像"活宠物" | M4 可选 |

**状态 → 照片映射**（`PetRenderer` 数据驱动，可替换素材）：

| 状态 | 默认照片 | 说明 |
|---|---|---|
| `idle` 待机 | `img_2`（沙发蜷缩）/ `img.png`（探头） | 轮流切换，叠加轻微呼吸/摆动动画 |
| `reminding` 提醒 | `img_5`（篮筐抬头）/ `img.png`（看向镜头） | 提醒时切到"看向镜头/抬头"姿态 |
| `celebrate` 庆祝 | `img.png`（看向镜头） | 事项完成 |
| `sleep` 睡眠 | `img_4`（躺平） | 晚间/长时间无操作 |

> 均为静态照片，非真动画帧；用 `Canvas` 做轻微位移（呼吸缩放、左右摇摆、眨眼遮罩）制造"活着"的观感。

**性格系统（用户可选，数据驱动）**：`PetPersonality` 通过 plist/JSON 定义，用户可在设置中切换；**决定提醒文案风格、语音语速/音调、待机互动台词与动画倾向**。v1 内置 4 套（名称与台词可再定）：

| 性格 | 性格标签（喂给 AI） | 语音（语速/音调） | 待机/互动 |
|---|---|---|---|
| 元气 | 热情、活泼、爱用「冲鸭/加油」，偶尔卖萌 | 偏快、音调偏高 | 频繁换姿态/台词 |
| 慵懒 | 懒洋洋、随性、慢节奏，「慢慢来」 | 慢、音调偏低 | 少动，常躺平 |
| 傲娇 | 嘴硬心软、别扭，「才不是催你」 | 中等、轻微上扬 | 偶尔回头"哼" |
| 高冷 | 话少、冷静、直接 | 快、平淡、低音 | 极简，几乎不动 |

- 每套性格下可再自定义称呼（"主人/宝贝/同学/无称呼"）与提示语；**性格标签会作为 prompt 的一部分喂给大模型**（见 §4.9）。
- 性格选择持久化于 `app_meta`；新增性格只需加数据，无需改代码。

**宠物状态机（`PetEngine`）**：

```
idle ──提醒点到──▶ reminding（放大+说话+气泡文字）
  ▲                    │ 播报完成
  │                    ▼
celebrate ◀─完成事项──(回到 idle)
sleep  ←─长时间无操作/夜里（呼吸变慢或隐藏）
```

**交互**：单击 → 随机互动/换台词（随性格与 AI）；双击 → 打开待办；拖动 → 移动；右键 → 切换宠物/隐藏。

**资源控制**：idle 时动画帧率降到几 FPS；提醒时短时全速；长期无操作进入 sleep。见 §7。

### 4.8 语音播报（TTS，F2/F5 共用）

- **引擎**：`AVSpeechSynthesizer`（`AVFoundation`），本地 TTS；`AVSpeechSynthesisVoice.speechVoices()` 枚举系统中文音色，设置里可**试听并选择音色 + 调语速**（`AVSpeechUtterance.rate`）。
- **文案输入**：优先取 `CopyGenerator` 生成的 AI 文案（见 §4.9）；若不可用，取**本地模板文案**。
- **性格音频**：语速/音调可由所选性格预设（元气快高、慵懒慢低、高冷低调）。
- **通道策略**：
  - 语音 + 系统通知双通道，**语音永远是增强而非替代**通知；
  - 勿扰/专注（Focus）模式下是否继续语音，给开关（默认关）；
  - 音量 0 / 静音时，通知横幅兜底，避免"错过"。
- **隐私/权限**：语音为纯输出，无需麦克风权限；v1 不做语音识别。
- **可暂停/跳过**：快捷"跳过本次/本时段语音"，避免打扰。

### 4.9 文案生成（AI 大模型接入，F6）

**功能**：提醒到点时，调用用户配置的大模型，基于「事件信息 + 剩余时间 + 宠物性格/名字」生成一句简短、自然、符合性格的提醒文案，再交给 TTS 播报。

**配置结构（`LLMProviderConfig`，用户可在设置面板填写）**：

| 字段 | 说明 | 示例 |
|---|---|---|
| `provider` | 供应商类型 | `openaiCompatible` / `anthropic` / `local`(Ollama) |
| `baseURL` | 接口地址（OpenAI-compatible 均自带 `/v1`） | `https://api.deepseek.com/v1`、`https://dashscope.aliyuncs.com/compatible-mode/v1`、`http://localhost:11434/v1` |
| `modelName` | **模型名称（用户输入）** | `deepseek-chat`、`qwen-plus`、`glm-4`、`claude-3-5-haiku`、`llama3.1` |
| `credential` | 凭证（二选一） | `apiKey`（单值）；或 **`ak`/`sk`（accessKeyId + secretAccessKey）**，适配阿里云 DashScope 等授权型 |
| `temperature` | 采样温度（默认 0.7） | 0.0–1.0 |
| `maxTokens` | 输出上限（默认 64） | 文案短，够用即可 |
| `timeout` | 请求超时（默认 5s） | 超时走模板兜底 |
| `enabled` | 开关 | 开启走 LLM；关闭则仅模板 |

> **凭证存储**：apiKey / AK·SK **写入 macOS Keychain**；`app_meta` 仅存非敏感字段（provider/baseURL/modelName/temperature/开关）。**绝不明文落盘、不打印日志**。支持「测试连接」按钮校验模型与密钥。

**宠物名字**：**咪咪**（默认，可在设置修改；会作为人设进入 prompt 与台词）。

**混合文案策略（已确认）**：`CopyGenerator` 先取**每套性格自带的「人设 base 台词」**，开启 AI 后再由模型**润色**；AI 不可用则直接用 base 台词——既有性格底色，又稳定不失效。

- **人设 base 台词**：每套性格在 bundle 的 `pet_personas.json` 内置 1–2 条带占位符的 base 句子，如元气「冲鸭！『{title}』还有 {n} 分钟就要截止啦！」、傲娇「才、才不是在催你！『{title}』只剩 {n} 分钟了！」。
- **AI 润色**：开启后，`prompt` = 性格标签 + 宠物名字（咪咪）+ base 台词 + 事件信息（标题/分类/截止/剩余分钟/紧急度）+ 1–2 个 few-shot → 让模型**在 base 基础上改写得自然、贴合性格**，仍输出一句话、`≤30 字`、口语化。
- **prompt 设计**：System 人设（咪咪 + 性格标签 + 角色说明 + 输出约束）；User 输入（base 台词 + 事件信息 + few-shot）。
- **输出处理**：清洗（去重/截断/去引号），转给 TTS。

**降级/兜底（关键）**：`CopyGenerator` 始终有 base 台词垫底，任何情况不阻断提醒：

```
提醒到点
  → 取该性格人设 base 台词（始终存在）
  → enabled 且配置合法 且 网络可用？
      是 → Call LLM 润色（带 timeout）
            成功 → 润色文案 → TTS
            失败/超时/限流/解析异常 → base 台词 → TTS
      否 → base 台词 → TTS（离线/无 key 也保证播报）
```

- 结果可按「提醒点 id」**缓存**，避免同一提醒重复计费；失败可指数退避重试一次。
- **隐私**：开启 AI 时会把「事件标题/分类/剩余时间 + base 台词」发送至所配 LLM；设置中提供**独立开关**与提示；敏感内容可关闭 LLM 或用本地模型（Ollama）实现全离线。

### 4.10 导入 / 导出（F4）

> 云同步已**砍掉**（CloudKit 需开发者签名 + entitlements + iCloud 容器），数据仅存本机；用导入/导出做备份与跨软件交换。

**导出**：
- **ICS 导出**：生成 ICS v2.0（含 `VALARM` 闹钟），可导入系统日历 / Google / Outlook。
- **CSV 导出**：标题/开始时间/分类/全天/完成态/提醒，用于表格软件。

**导入**：
- **ICS 导入**：解析 ICS v2.0（含换行折叠、UTC/本地/全天日期），导入为事件（`source=ics`）。
- 去重：按 title + startDate 近似去重（v1 简化）。

### 4.11 主窗口 / 菜单栏 / 设置

- **主窗口**：月视图大日历 + 事项详情面板；拖拽建事项、双击编辑。
- **菜单栏常驻**（`MenuBarExtra`）：今日概览、显示/隐藏桌面层、显示/隐藏宠物、快速记一笔、设置、退出。无 Dock 图标时菜单栏是唯一退路。
- **设置面板**（Tab）：
  - 通用：启动登录项、Dock 图标显隐、默认周起始日；
  - 外观：桌面层形态（三态）、主题（玻璃/霓虹/渐变/极简/自定义）、透明度、动画强度、性能模式、跟随壁纸取色；
  - 农历：节气/节日/宜忌开关；
  - 提醒：默认方案（频率选择）、语音开关、音色、语速、提前量、Focus 下是否语音、迟到补偿；
  - 宠物：显示/隐藏、**性格选择（元气/慵懒/傲娇/高冷）**、当前形象与姿态预览、动画强度、提示语、位置记忆、音量；
  - **AI 助理**：启用开关、供应商类型、baseURL、**模型名称**、**apiKey / AK·SK**、temperature、测试连接、隐私提示（是否把事件信息发送至大模型）；
  - 同步：账号状态、最近同步时间、手动立即同步、导出/导入入口。

## 5. 数据持久化设计

- 单机首选 **SQLite（GRDB）**，库文件放 `Application Support/<bundle id>/`。
- 表：
  - `event`（记事/待办主体，字段见 §4.4）；
  - `reminder`（每个提醒点：归属 event、offsetMinutes、scope、label、**生成的 AI 文案缓存**）——**一对多**，见 §4.6 / §4.9；
  - ~~`sync_meta`（CloudKit 同步元数据）~~ 已随云同步移除；
  - `app_meta`（键值：桌面层窗口位置/尺寸/形态、主题与外观、宠物设置（**名字（默认咪咪）** /形象/性格/位置/音量/提示语）、提醒默认方案、**AI LLM 非敏感配置（provider/baseURL/modelName/temperature/开关）**、用户偏好）。
- **LLM 凭证**：apiKey / AK·SK 存 **Keychain**（`kSecClassGenericPassword`，按 bundle id + account 存取），绝不出现在 `app_meta`。
- 宠物素材：`pics/` 目录随打包附带的只读资源，通过 `PetRenderer` 数据映射加载；**性格定义（性格标签 + 人设 base 台词）放 bundle 内 `pet_personas.json`**，便于后续追加性格。
- 轻量考虑：桌面日历每日仅读写当天事件，查询以 `startDate` 索引；几千条规模下 SQLite 无需优化即可毫秒级。
- 备份：用「数据」Tab 的 ICS/CSV 导出手动备份迁移（已移除云同步）。

```
  → 同上，按性格重新生成/复用缓存，重复播报

  → 宠物 celebrate；撤销剩余 pending 提醒
```

## 7. 非功能需求

| 项 | 要求 |
|---|---|
| 资源占用 | 常驻内存 < 150MB；无操作时动画停帧/≤5fps，CPU≈0；用节流 + 惰性渲染，避免整窗口逐帧重绘 |
| 启动 | 登录项自启，冷启动到出现桌面层 < 2s（先骨架后异步补数据） |
| 稳定性 | 桌面层/宠物窗口崩溃或被系统回收后能自愈（周期性自检层级）；数据先落本地，同步失败不影响写；**AI 文案失败不阻断提醒** |
| 语音/音频 | 串行播报不重叠；勿扰/静音时通知兜底；可一键跳过 |
| AI 延迟/可用性 | LLM 调用 timeout（默认 5s）+ 模板兜底，避免让用户等待播报；失败不重复打扰 |
| **AI 隐私** | 发送 LLM 的内容最小化（标题/分类/剩余时间）；**用户确认后才启用**；支持本地模型全离线；密钥入 Keychain 不落日志 |
| 无障碍 | 日期格提供 VoiceOver 标签；字号可调；颜色辅以符号（色盲友好）；宠物图片提供替代文本 |
| 多屏 | 桌面层/宠物位置按 Screen 记忆；断开外接屏回退主屏 |
| 多语言 | 优先中/英；抽离 `String Catalog` |
